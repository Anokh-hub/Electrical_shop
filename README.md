# ⚡ Electrical Shop

A modern, responsive website for an electrical shop that helps customers explore electrical products, find the shop location, and contact the shop directly.

🌐 **Live Demo:** https://electrical-shop-eta.vercel.app/

## 📌 About the Project

Electrical Shop is a frontend web application designed to improve the online presence of a local electrical store. It provides customers with an easy way to discover the shop, view available product information, and get in touch with the shop owner.

The website is designed with a focus on simplicity, accessibility, and mobile responsiveness.

## ✨ Features

- 🏪 Electrical shop information
- 💡 Electrical products showcase
- 📍 Google Maps location integration
- 📞 Direct calling functionality
- 💬 WhatsApp contact integration
- 📱 Responsive design for mobile, tablet, and desktop
- ⚡ Fast and modern user interface

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Language:** JavaScript
- **Deployment:** Vercel
- **Integrations:** Google Maps, WhatsApp, and phone calling

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Anokh-hub/Electrical_shop.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Electrical_shop
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
